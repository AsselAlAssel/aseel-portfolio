# Aseel Hussain Al-Ali — Portfolio

Production-quality single-page portfolio built with React, Vite, TypeScript, Tailwind CSS, Framer Motion, and Lucide React.

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run lint
npm run build
```

## Edit portfolio content

- Projects: `src/data/projects.ts`
- Experience: `src/data/experience.ts`
- Skills: `src/data/skills.ts`
- Social links: `src/data/socials.ts`
- Hero copy and statistics: `src/components/hero/HeroContent.tsx`
- About copy and qualities: `src/components/about/About.tsx`
- Contact copy: `src/components/contact/Contact.tsx`
- Theme tokens and visual system: `src/index.css`
- Portrait assets: `src/assets/images/`
- Downloadable CV: `public/aseel-al-ali-cv.pdf`
